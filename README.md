# UE5 Production Pipeline Toolkit

A modular Unreal Engine Editor tooling prototype
for game production pipeline workflows.
Project uses Unreal Engine 5.8.2 and its standard engine plugins.

## Current Status

V0 - Editor Plugin + Slate Toolkit

### Implemented

- Unreal Engine Editor Plugin
- Editor Module lifecycle
- Dockable Editor Tab
- Slate-based UI
- Basic button interaction
